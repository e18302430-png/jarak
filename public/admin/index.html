التطبيق يفهم قوائم المقاضي اللي يلصقها العميل بدون أي مفتاح. المفتاح يضيف: فهم أدق للهجة، وتصوير ورقة المقاضي، والتسجيلات الصوتية.

كيف تجيب المفتاح (مجاني، دقيقتين)

  1. افتح aistudio.google.com/apikey وادخل بحساب جيميل.
  2. اضغط Create API key وانسخ المفتاح (يبدأ بـ AIza).
  3. الصقه هنا واضغط «احفظ المفتاح»، وبعدها «جرّب الفهم».
